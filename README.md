# TunaMan Extreme

**TunaMan Extreme** is a fast-paced Unity 2D platformer, created in just 24 hours during a game jam in 2020!

## 🎮 Game Overview

Dive into the action as TunaMan, navigating challenging levels, dodging obstacles, and racing against time. Designed for quick and exciting gameplay sessions, TunaMan Extreme tests your reflexes and platforming skills.

## 🚀 Features

- **Classic 2D Platformer Mechanics**: Jump, dash, and avoid hazards.
- **Game Jam Spirit**: Developed in 24 hours—rapid prototyping, quirky fun!
- **Unity Engine**: Built in Unity for smooth controls and polished visuals.

## 🕹️ How to Play

1. Download or clone this repository.
2. Open the project in [Unity](https://unity.com/).
3. Play from the editor, or build for your preferred platform.

## 📦 Installation

```bash
git clone https://github.com/macetini/TunaManExtreme.git
```
Open the folder in Unity and run the game!
